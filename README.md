# vmeste_app
Сервис совместного выбора досуга «Вместе» (VK Mini App)
## 1. Общая информация
* **Формат продукта:** Веб-приложение с нативной интеграцией в **VK Mini Apps** (запуск прямо внутри ВКонтакте).
* **Целевая аудитория:** Компании друзей, пары, студенческие группы и коллеги, которым нужно быстро договориться о выборе фильма на вечер или заведения для встречи без долгих споров в чатах.
* **Команда разработки:** 5 человек (студенты 3 курса).
* **Срок реализации MVP:** .

---

## 2. Ключевой функционал
* **Авторизация и социальные механики (VK Mini Apps):** Бесшовный вход в 1 клик через `vk_user_id` с проверкой криптографической подписи на бэкенде, загрузка имени и аватарки профиля, отправка приглашений в беседы ВК через `@vkontakte/vk-bridge`.
* **Живой контент из внешних API:** Загрузка фильмов, постеров и рейтингов через **Kinopoisk Unofficial API** и поиск кафе/ресторанов рядом по геолокации через **Overpass API (OpenStreetMap)** с кэшированием в БД.
* **Режим реального времени (WebSockets):** Живое лобби со статусами друзей (*«готов»*, *«свайпает»*, *«закончил»*) и мгновенное всплывающее окно при **100% Match**.
* **Игровая механика и умный алгоритм подбора:** Обычный лайк (`+1`), **Суперлайк** (`+3`, 1 раз за игру), **Вето** (мгновенный бан карточки для всей комнаты) и финальный баттл **«Царь горы» (1 на 1)** с таймером.
* **Личный кабинет и аналитика:** История прошедших комнат, личный вишлист («Хочу посмотреть / сходить») и статистика любимых жанров/кухонь.

---

## 3. Архитектура и стек технологий
* **Backend:** Python 3.11+, FastAPI, Uvicorn, WebSockets, `asyncio`, `httpx`
* **База данных:** MS SQL Server (`pymssql`) / PostgreSQL
* **Frontend:** HTML5, CSS3 (Tailwind CSS), Vanilla JS, `@vkontakte/vk-bridge`
* **Инфраструктура:** Git, GitHub, Docker, VPS (Nginx + HTTPS)

---

## 4. Распределение ролей в команде (5 человек)
1. **Лидер 1 (Backend & Real-time Lead):** Архитектура репозитория, авторизация ВК, менеджер WebSockets (`RoomManager`), стыковка модулей и деплой.
2. **Лидер 2 (Frontend, UX & VK Bridge Lead):** Вёрстка мобильного интерфейса, плавная физика свайпов карточек на JS, интеграция с `@vkontakte/vk-bridge` и связка с бэкендом.
3. **Разработчик 3 (БД и Личный кабинет):** Проектирование 5 таблиц БД, слой работы с данными, SQL-запросы для истории игр, вишлиста и статистики вкусов.
4. **Разработчик 4 (Внешние API и Геолокация):** Интеграция с Kinopoisk API и Overpass API, кэширование карточек в базу данных и фильтрация по координатам.
5. **Разработчик 5 (Игровая логика и Турнир):** Подсчёт весов голосов, механика «Вето», асинхронные таймеры и логика финального раунда «Царь горы».
